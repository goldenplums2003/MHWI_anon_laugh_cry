# MHW 太刀 登龙 / 大居 成败语音

《怪物猎人：世界 / 冰原》太刀专用的 LuaEngine 脚本：**登龙（气刃兜割）和大居（居合抜刀气刃斩）打中或打空时，分别播放爱音唐笑和爱音唐哭。**

---

## 效果

| 招式 | 判定成功 → 播 `tangxiao.wav` | 判定失败 → 播 `tangku.wav` |
| --- | --- | --- |
| 登龙（气刃兜割） | 打出了伤害 | 完全打空 |
| 大居（居合抜刀气刃斩） | 没掉刃 **且** 打出了伤害 | 掉刃，或没打出伤害 |

---

- **[LuaEngine](https://github.com/HalcyonAlcedo/LuaEngine)**（HalcyonAlcedo）—— 需要 `LuaEngine.dll` 和 `LuaEngineAudio.dll` 两个，音频播放靠后者
- 一个能加载 Stracker's Loader 插件的环境（`dinput8.dll` + `loader.dll` + `nativePC/plugins/`）

## 安装

### 用狩技MOD盒子

直接把 release 里的 zip 丢给盒子安装即可。

```
Lua/ls_denglong_voice.lua
nativePC/Music/3/tangxiao.wav
nativePC/Music/3/tangku.wav
```

### 手动安装

把上面这两个目录按原样复制到游戏根目录（`Monster Hunter World\`）。

> 如果你**同时**手动放过文件又用盒子装，会出现「盒子里显示关闭、但 mod 还在响」的情况——盒子只管它自己装的文件，删不掉你手动放的。二选一。

装好后**重启游戏**，脚本是启动时加载的。

---

## 换成自己的音频

替换 `nativePC/Music/3/` 下的两个文件即可，文件名保持不变：

- `tangxiao.wav` —— 成功时播放
- `tangku.wav` —— 失败时播放

格式很宽松，44.1kHz / 48kHz、16bit / 32bit 都能放。两点建议：

1. **把开头的静音裁掉。** 前导静音会直接变成听感上的延迟。
2. **两段音频的响度对齐。** 否则会一个震耳一个听不清。

## 配置

改 `Lua/ls_denglong_voice.lua` 开头的 `CONFIG`：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `volume` | `51` | 音量 |
| `onlyRed` | `false` | 改 `true` 则只在红刃（练气 3）时触发 |
| `silent` | `false` | 改 `true` 则只判定、不放音（调试用） |
| `hud` | `false` | 屏幕显示「成功 / 失败」提示，**Ctrl+D** 可随时切换 |
| `verbose` | `false` | 把每次动作切换和每笔伤害都写进 `logs/LuaEngine.log` |
| `collect` | `false` | 记录从居合姿态出来的、脚本还不认识的动作（扩展新招式时用） |

判定结果一律会写进 `logs/LuaEngine.log`，方便核对：

```
[太刀] 登龙 成功   [damage/提前]   伤害 598->1008   练气 1->0
[太刀] 大居 失败   [both/提前]     伤害 5914->5914  练气 3->2   下一动作=49163
```

## 判定是怎么做的

音频库和游戏的动作状态机都**没有**「这一下打中了没有」这种可以直接播不同音效的开关，所以判定得自己算：

1. 通过 `Player.Action.lmtID` 认出你正在放哪个招式
2. 招式**开始**时记下当前的任务累计伤害、怪物血量总和、练气等级
3. 招式**进行期间**持续对比 —— 伤害涨了或怪掉血了，就锁定「打中了」
4. 结果一旦确定就立刻出声，**不等动作放完**

第 3 步在过程中判而不是等结束再比对，是为了避免「招式结束」的时机判断有偏差时误判。第 4 步是延迟的主要来源：登龙的伤害往往在动作前半段就落地，等整套动画放完再出声会明显迟。

有两种情况从原理上必须等到动作结束，砍不掉：

- **登龙落空** —— 不到最后一刻无法确认真的空了
- **大居成功** —— 要等练气最终没掉才能确认

## 已知限制

- **无刃（练气 0）状态下的大居不判定。** 大居在每个刃色下是不同的动作 ID（`49461` 白 / `49462` 黄 / `49463` 红），而无刃状态似乎有多个 ID 变体，只确认过一个，没抓全。想自己加的话：把 `collect` 打开，无刃下只放大居、重复几次、别接任何后续动作，然后翻 `logs/LuaEngine.log` 里的 `[太刀待认]`，把冒出来的 ID 全部加进 `MOVES` 里大居的 `mains`。
- **登龙落空 / 大居成功有固有延迟**（原因见上）。

## 附录：实测的太刀动作 ID

想扩展别的招式的话，这些是已经确认过的：

| 动作 ID | 是什么 |
| --- | --- |
| `49326` | 登龙（气刃兜割）—— **三个刃色共用这一个** |
| `49461` / `49462` / `49463` | 大居 —— 白刃 / 黄刃 / 红刃，各自独立 |
| `49458` | 特殊纳刀 |
| `49322` | 气刃突刺 |
